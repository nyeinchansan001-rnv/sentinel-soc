# Dashboard Report

## Dashboard Name
SOC Security Monitoring Dashboard

## Purpose
The dashboard provides a centralized view of security events collected in Splunk.

## Panels
1. HTTP Status Codes
2. Web Requests Over Time
3. Top Attacker IPs
4. Top Requested URLs
5. Recent Security Events
6. Top User Agents

## Result
The dashboard allows analysts to monitor web activity and security events in real time.
