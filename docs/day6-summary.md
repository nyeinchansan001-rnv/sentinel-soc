# Day 6 – SOC Dashboard Development

## Objective
Build a Splunk dashboard to visualize security events.

## Dashboard Panels
- HTTP Status Codes (Pie Chart)
- Web Requests Over Time (Line Chart)
- Top Attacker IPs (Bar Chart)
- Top Requested URLs (Bar Chart)
- Recent Security Events (Table)
- Top User Agents (Bar Chart)

## Outcome
A centralized dashboard was created to monitor web traffic and security-related events using Splunk visualizations.
